## 4. O produto

O OBS Stream Tools reúne:

- **OBS Deck**, para controle remoto de cenas, fontes, gravação, transmissão e outras funções compatíveis do OBS Studio;
- **Controle PTZ**, para operação de câmeras compatíveis com VISCA over IP por joystick, setas, zoom e presets.

## 5. Requisitos técnicos

O funcionamento exige:

- OBS Studio com WebSocket habilitado;
- OBS Control Server instalado no computador principal;
- navegador moderno em celular, tablet ou computador;
- dispositivos conectados à mesma rede local confiável ou por VPN privada;
- câmera compatível com VISCA over IP para os recursos PTZ;
- rede, firewall, equipamentos e credenciais corretamente configurados.

Alterações no OBS Studio, navegadores, sistemas operacionais, câmeras, firmwares ou demais componentes de terceiros podem afetar a compatibilidade.
